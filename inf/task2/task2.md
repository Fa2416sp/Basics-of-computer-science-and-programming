# Task 2  

## Нужный этаж Задание

### **1 Создание каталога и файлов:**
- Создайте каталог `task2` в каталоге `inf`.
- В каталоге `inf/task2` создайте файл `fixes.log` для ведения журнала исправлений.
- Создайте файл `main.c` с содержимым, которое вы предоставили.
```C
int main()
{
    // Номер квартиры
    int flat_number;

    /* Число квартир на этаже */
    int flats_per_floor;

    /* Запрашиваем квартиру, в которой проживает адресат */
    printf("Введите номер интересующей квартиры: ");
    scanf("%d", &flat_number);

    /* Запрашиваем число квартир на этаже */
    printf("Введите число квартир на каждом этаже: ");
    scanf("%d", &flats_per_floor);

    /* Рассчитываем и выводим номер этажа */
    printf("Вам нужно подняться на %d этаж\n", (flat_number - 1) / flats_per_floor + 1);

    return 0;
}
```
### **2 Создание Makefile:**
- Создайте файл `Makefile` в каталоге `inf/task2`:
```Makefile
main: main.o
        gcc -o main main.o

main.o: main.c
        gcc -g -O0 -c -Wall -Wextra main.c

clean:
        rm task1 *.o

indent:
        indent -kr -nut main.c
```
### **3 Сборка программы:**
- В каталоге `inf/task2` выполните команду `make`.
```Shell
make
```

### **4 Проверка программы:**
- Запустите программу и убедитесь, что она правильно вычисляет номер этажа для различных тестовых данных.
```Shell
./main 
```
